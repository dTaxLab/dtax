## @dtax/tax-engine — AGPL-3.0

El paquete npm `@dtax/tax-engine` está licenciado bajo la **GNU Affero General Public License v3.0**.

### Puedes

- Usarlo en proyectos personales de forma gratuita
- Estudiar y modificar el código fuente
- Distribuir versiones modificadas (deben mantenerse bajo AGPL-3.0)
- Usar el motor sin modificar de forma comercial, en un producto o servicio, sin licencia comercial, siempre que cumplas los términos de la AGPL-3.0
- Usarlo internamente sin publicar el código fuente (solo uso interno)

### Debes (si distribuyes)

- Incluir el texto completo de la licencia AGPL-3.0
- Publicar todas las modificaciones bajo AGPL-3.0
- Si modificas el motor y los usuarios interactúan con él a través de una red, ofrecer a esos usuarios el código fuente de tu versión modificada (AGPL sección 13)

### Considera una Licencia Comercial si

- Quieres mantener tus modificaciones como código propietario y ofrecerlas a usuarios a través de una red
- Tu equipo legal no puede aceptar las obligaciones de la AGPL, o no puedes confirmar que tu aplicación no es una obra combinada con el motor
- Necesitas la aplicación web y la API REST bajo condiciones comerciales
