## @dtax/tax-engine — AGPL-3.0

The `@dtax/tax-engine` npm package is licensed under **GNU Affero General Public License v3.0**.

### You CAN

- Use it in personal projects for free
- Study and modify the source code
- Distribute modified versions (must remain AGPL-3.0)
- Use the unmodified engine commercially, including in a product or service, without a commercial licence, provided you comply with the AGPL-3.0 terms
- Use it internally without open-sourcing (internal use only)

### You MUST (if distributing)

- Include the full AGPL-3.0 license text
- Open-source all modifications under AGPL-3.0
- If you modify the engine and users interact with it over a network, offer those users the source of your modified version (AGPL section 13)

### Consider a Commercial License if

- You want to keep your modifications proprietary while offering them to users over a network
- Your legal team cannot accept AGPL obligations, or you cannot confirm that your application is not a combined work with the engine
- You need the web application and REST API under commercial terms
